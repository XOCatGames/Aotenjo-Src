# 图片来源 / Artwork provenance

All tutorial PNGs are copied without modification from the four images already present in this repository before the rewrite, at commit `b51d2b9`:

- `example/mods/ex1_artifact/texture/artifact/coin_number_2.png`
- `example/mods/ex1_artifact/texture/artifact/kong_jade.png`
- `example/mods/ex3_tile_material/texture/tile_material/ruby.png`
- `example/mods/ex3_tile_material/texture/tile_material/sapphire.png`

所有示例图片直接复用重写前仓库已公开的四张教学图片，未从私有游戏资源导出新图片。硬币同时用作预览、合成代币和材质包替换图；练习玉复用旧 kong_jade 图。示例重点是文件齐全、ID可验证，图标不是新的正式游戏美术。

The coin is reused for previews, recipe tokens, and the texture replacement; Practice Jade reuses the old kong_jade image. These are complete teaching assets, not newly commissioned game artwork. Existing repository/file rights remain applicable; this rewrite does not grant a new license to third-party or game assets.
