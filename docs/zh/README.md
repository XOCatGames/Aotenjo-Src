# 从想法到可运行模组

[English](../en/README.md) · [仓库首页](../../README.md)

读者只需要会 Lua 的变量、函数、条件、循环和 table。无需安装 Unity、编译 C#、了解 Shader，便可完成这里的七个示例。C# 类型和 xLua 转换规则会在需要时说明。

## 学习路线

1. [快速上手](quickstart.md)：找到目录、复制文件、看到日志，做出第一个藏品。
2. [Lua 与游戏对象](lua-bridge.md)：读懂 `CS`、点和冒号、数组、回调、效果队列。
3. 按想法选择：[藏品](artifacts.md)、[番种](yakus.md)、[牌材质](materials.md)、[合成](recipes.md)、[材质包与配色](textures.md)。
4. [图片与双语文本](assets.md)：把名字、说明、图标接起来。
5. [玩法改造食谱](cookbook.md)：组合条件、数值、随机性和持久状态。
6. [测试、排错、发布](testing.md)：用确定输入验证，然后分享模组。

## 当前能做什么

| 想法 | 当前入口 | 边界 |
| --- | --- | --- |
| 特定牌加分、赚钱、弃牌或关末触发、成长藏品 | `LuaArtifactBuilder` | 各回调参数不同，使用传入的 `player` |
| 自定义番种条件、继承、加入已有番种包 | `CustomYakuBuilder` | 判定、可用范围、包索引、继承分别设置 |
| 自定义牌材质效果、创建可选材质组 | `LuaTileMaterialBuilder`、`LuaMaterialSetBuilder` | 注册材质不等于给手牌应用它 |
| 将若干不同藏品合成结果 | `LuaArtifactRecipeBuilder` | 输入是物品集合条件，不是数量配方 |
| 替换现有图片 | `texture-pack.json` | 只改外观；整张贴图尺寸必须匹配 |
| 改已有字体的色彩、渐变、深度 | `TileFaceMaterialRegistry` | 注册外观不会创建新字体的玩法规则 |
| 新 Boss、小道具、麻将套组、地点、番种包类型 | 尚无对应 Lua Builder | C# 类存在不代表有完整 Lua 注册/复制/存档支持；此手册不提供虚构注册函数 |

你可以调用已公开 C# 方法，但内部实现不等于长期稳定的模组契约。先选最小的现有扩展点；查看[源码签名索引](../../reference/api-signatures.md)及链接源码确认参数。超出上表的想法，可以提出所需的扩展点，不能靠重命名一个 Lua 函数凭空添加接口。

## 一条可完成的验收任务

复制藏品示例，将 ID 改成自己的前缀，把“打出二得2金币”改成“打出九加15符”，更新中英文说明；安装后用 `setHand 999m123p` 和自己的 `give` 指令验证九触发、非九不触发、历史落定牌不重复触发。然后退出重进、与另一示例共存，按[验收表](testing.md)检查。能独立完成这一轮，便掌握了从想法、条件、效果到交付的完整路径。
